# Storybook → buck2 containment (handoff)

Goal: `buck2 build //storybook:static` builds `storybook-static/` hermetically
(nix-provided node_modules, no ambient `bun install`), instead of the standalone
`build-bundle.sh && bunx storybook build`.

This is **wiring existing, exposed machinery** — not a rewrite. The prelude already
exposes `npm_build` (a buck2 action that assembles a node_modules from a resolved
closure and runs an arbitrary build command over it, capturing one output dir) and
a `toolchain.purescript.bun2nix` option. Same shape the Clerk integration uses.

## Done (committed)

- **`bun.nix`** — the hermetic node_modules manifest, generated by
  `nix run github:nix-community/bun2nix/2.1.0 -- -l bun.lock -o bun.nix`
  (every Storybook/Vite dep, sha512-pinned). Re-run after changing `package.json`.

## Remaining (the build-tool thread — slow nix-eval + buck-build cycles)

1. **Wire the node_modules into the toolchain** in hydrogen's `flake.nix`, under
   `straylight-prelude.projects.hydrogen-ps.toolchain.purescript.bun2nix`:

   ```nix
   bun2nix.storybook = <node_modules built from ./storybook/bun.nix>;
   ```

   built via the bun2nix flake's node-modules assembler (`fetchBunDeps` /
   `mkBunNodeModules` over `bun.nix` — see the bun2nix 2.1.0 lib API + the
   `toolchain.purescript.bun2nix` option doc in
   `straylight-prelude/nix/modules/flake/straylight-prelude/options.nix:145`).
   This regenerates `.buckconfig.local` with `[purescript] bun2nix_storybook = …`.

2. **Add the `//storybook:static` target** (BUCK), consuming that closure:

   ```python
   npm_build(
       name = "static",
       srcs = glob([".storybook/**", "stories/**"]) + [
           "package.json",
           "themes.css",
           ":bundle",            # the Halogen FFI bundle (dist input)
       ],
       npm_packages = "bun2nix#storybook",
       # storybook's CLI from the hermetic tree; -o writes into out_dir
       cmd = "node node_modules/storybook/index.cjs build -o $OUT",
       out_dir = "storybook-static",
   )
   ```

   Then `nix develop -c buck2 build //storybook:static`.

### Known wrinkles to iron in that thread

- The exact Storybook 8 CLI entry in the hermetic tree (`node_modules/storybook/…`
  vs `node_modules/.bin/storybook`) and how it receives the output dir.
- `staticDirs: ["../dist"]` — the bundle + `themes.css` must be staged where the
  build expects them (pass `:bundle` + `themes.css` as srcs; point staticDirs at
  the staged path, or inline the `<link>`/`<script>` in `preview-head.html`).
- Vite/Storybook writing to `$HOME`/cache/telemetry under the sandbox — set
  `STORYBOOK_DISABLE_TELEMETRY=1` and a writable cache dir in `cmd`.

## Note

The golden factory (`testing/golden/themes`) and the Playwright harness
(`testing/playwright`) are the same standalone-bun shape; containing all three is
one effort. Orthogonal to build *speed* (the 15s whole-closure `purs compile`) —
that's a warm purs+esbuild watch loop or an incremental `_compile`, not bun2nix.
